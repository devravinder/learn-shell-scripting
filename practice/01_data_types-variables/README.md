# Data types & Variables

## Data types
 - Data types tells about the data ( to the language/computer)
    - what kind of data
    - what operations / actions can be performed


### Types
1. Strings
2. Integers / Numbers
3. boolean
4. arrays 
   - indexed array ( fixed )
   - Associative Array ( dynamic )




## Variables
- variable is memory to store data ( data types )
- variables are used to store the data, and to access them again ( in a programming )
- variables allow us
    - to store & reuse the data
